# Course 3D

Learn some tech vividly：用等距动画和故障场景讲技术。

## 课程

- [Kafka 互动课程（22 课）](https://bracken1022.github.io/course_3d/kafka/)：订单系统场景，故障驱动学习。从同步调用的问题讲起，覆盖 Partition、Consumer Group、Offset 与 Lag、副本与 ISR、Rebalance、Retention、Key 与顺序、幂等 Producer、Lag 排查、热点 Partition、DLT、Backpressure、Schema Evolution、事务、Outbox、CDC、Kafka Streams 和安全。

- [RabbitMQ 入门互动课（8 课）](https://bracken1022.github.io/course_3d/rabbitmq/)：从为什么需要消息队列讲到核心概念、工作队列、发布 / 订阅、路由、可靠性和实战选型。

每门课都是一个独立的 HTML 文件，下载后可离线打开（RabbitMQ 课程在线时会加载 Google Fonts 字体，离线时自动换成系统字体）。答题进度只保存在浏览器本地。
